召回策略一：协同过滤 Item-CF

核心思想

喜欢商品A的用户也喜欢商品B
构建用户-商品行为权重矩阵 → 计算商品间余弦相似度 → 用相似度加权生成候选分

similarity(i, j) = co_occur(i, j) / √( normi × normj )
co_occur = Σ(wleft × wright) 同用户交互的商品对
norm = Σ(w²) 每个商品的行为权重平方和

Item-CF — 代码实现

// itemCf() — 用户行为 × 物品相似度 → 候选分数
private Map<Long, Double> itemCf(Long userId) {
    Map<Long, Double> mine = loadWeights(userId);   // 用户历史行为权重
    Map<Long, Double> scores = new HashMap<>();
    mine.forEach((id, w) ->
        similarity().getOrDefault(id, Map.of())
            .forEach((candidate, s) ->
                scores.merge(candidate, s * w, Double::sum)));
    return scores;
}

// similarity() — 余弦相似度矩阵构建
private Map<Long, Map<Long, Double>> similarity() {
    // Step 1: 用户-商品行为矩阵
    Map<Long, Map<Long, Double>> userMatrix = ...;
    // Step 2: 共现矩阵 co(i,j) = Σ(w_i × w_j)
    userMatrix.values().forEach(itemMap -> {
        itemMap.forEach((leftId, lw) ->
            itemMap.forEach((rightId, rw) -> {
                if (!leftId.equals(rightId))
                    co.computeIfAbsent(leftId, k -> new HashMap<>())
                      .merge(rightId, lw * rw, Double::sum);
            }));
    });
    // Step 3: 余弦相似度 = co / √(norm_i × norm_j)
    double base = Math.sqrt(norm.getOrDefault(itemId, 1.0)
                             * norm.getOrDefault(otherId, 1.0));
    inner.put(otherId, base == 0 ? 0 : score / base);
}

召回策略二：基于内容 Content-Based

匹配规则

用户画像（品类偏好 + 品牌偏好 + 兴趣标签）与商品属性逐项匹配打分

+2.0
品类偏好匹配
+1.4
近期浏览品类
+1.0
品牌偏好匹配
+0.5
兴趣标签匹配（每条）

Content-Based — 代码实现

private Map<Long, Double> content(Long userId, List<ProductEntity> active) {
    ProfileView profile = userService.getProfile(userId);
    Set<String> categoryPrefs = split(profile.preferredCategories());
    Set<String> brandPrefs = split(profile.preferredBrands());
    Set<String> interests = split(profile.interests());

    Map<Long, Double> scores = new HashMap<>();
    for (ProductEntity product : active) {
        double score = 0;
        if (categoryPrefs.contains(category))      score += 2.0;
        if (recentCats.contains(categoryId))      score += 1.4;
        if (brandPrefs.contains(brand))            score += 1.0;
        if (recentBrands.contains(brand))         score += 0.8;
        for (String interest : interests) {
            if (name.contains(interest) || desc.contains(interest)
                    || tags.stream().anyMatch(t -> t.contains(interest)))
                score += 0.5;
        }
        if (score > 0) scores.put(product.getId(), score);
    }
    return scores;
}

召回策略三：热度推荐 Hot

核心逻辑

近 7 天行为数据按行为权重累加 → 热度分
无行为数据时降级为商品自身 salesCount + recommendScore

hotScore(p) = Σ behaviorWeight   (近7天)   或   salesCount + recommendScore
浏览 ×1.0 搜索 ×1.5 收藏 ×3.0 加购 ×4.0 购买 ×5.0

Hot — 代码实现

private Map<Long, Double> hotScores() {
    LocalDateTime threshold = LocalDateTime.now().minusDays(7);
    List<UserBehaviorEntity> behaviors = userBehaviorMapper
        .selectList(new LambdaQueryWrapper<>()
            .isNotNull(UserBehaviorEntity::getProductId)
            .gt(UserBehaviorEntity::getCreatedAt, threshold));
    Map<Long, Double> scores = new HashMap<>();
    if (behaviors.isEmpty()) {
        // 系统级冷启动：降级为商品自身分数
        products.forEach(item -> scores.put(item.getId(),
            item.getSalesCount() + item.getRecommendScore()));
        return scores;
    }
    // 正常：按行为权重累加
    behaviors.forEach(item -> scores.merge(
        item.getProductId(), item.getBehaviorWeight(), Double::sum));
    return scores;
}

召回策略四：实时推荐 Realtime

核心逻辑

基于用户最近 5 条正向行为，在同品类商品间扩散推荐
引入时间衰减因子，越近的行为权重越高，捕捉短期兴趣漂移

decay(i) = 1.0 / (i + 1)    →    score = 0.8 × decay
i=0 → 1.0（最近）
i=1 → 0.5
i=2 → 0.33
i=3 → 0.25
i=4 → 0.20

Realtime + Cold Start — 代码实现

// realtime() — 最近5条行为 × 时间衰减 → 同品类扩散
private Map<Long, Double> realtime(Long userId, List<ProductEntity> active) {
    List<UserBehaviorEntity> recent = userBehaviorMapper
        .selectList(new LambdaQueryWrapper<>()
            .eq(UserBehaviorEntity::getUserId, userId)
            .gt(UserBehaviorEntity::getBehaviorWeight, 0)
            .orderByDesc(UserBehaviorEntity::getCreatedAt)
            .last("limit 5"));
    for (int i = 0; i < recent.size(); i++) {
        double decay = 1.0 / (i + 1);
        active.stream().filter(item -> sameCategory)
              .forEach(item -> scores.merge(id, 0.8 * decay, Double::sum));
    }
}

// coldStart() — 行为 < 5条时自动降级
private Map<Long, Double> coldStart(Long userId, List<ProductEntity> active) {
    Set<String> categoryPrefs = split(userService.getProfile(userId).preferredCategories());
    for (ProductEntity product : active) {
        double base = product.getSalesCount() + product.getRecommendScore();
        if (categoryPrefs.contains(categoryName(product.getCategoryId())))
            scores.put(product.getId(), base + 10);  // 品类偏好加分
    }
    return scores.isEmpty() ? hotScores() : scores;  // 兜底
}

核心融合公式

final_score = w₁ × norm(Item-CF) + w₂ × norm(Content) + w₃ × norm(Hot) + w₄ × norm(Realtime)
w₁ = 0.45 协同过滤
w₂ = 0.25 基于内容
w₃ = 0.20 热度推荐
w₄ = 0.10 实时推荐
// merge() — 四路加权融合
private Map<Long, Double> merge(Map a, double wa, Map b, double wb, Map c, double wc, Map d, double wd) {
    Map<Long, Double> result = new HashMap<>();
    a.forEach((id, s) -> result.merge(id, s * wa, Double::sum));
    b.forEach((id, s) -> result.merge(id, s * wb, Double::sum));
    c.forEach((id, s) -> result.merge(id, s * wc, Double::sum));
    d.forEach((id, s) -> result.merge(id, s * wd, Double::sum));
    return result;
}

// normalize() — Max-Normalization
private Map<Long, Double> normalize(Map<Long, Double> raw) {
    double max = raw.values().stream().mapToDouble(Double::doubleValue).max().orElse(1.0);
    return raw.entrySet().stream()
        .collect(Collectors.toMap(Map.Entry::getKey, e -> e.getValue() / max));
}

闭环机制详解

用户的每一次行为（浏览 / 搜索 / 收藏 / 加购 / 购买 / 反馈）都会被实时采集入库

通过 @Async("recommendExecutor") 异步触发推荐引擎重新计算，不阻塞用户请求

计算结果写入 Redis 缓存（TTL 30min）并持久化到数据库

前端展示推荐后，用户的点击 / 喜欢 / 不喜欢再次进入行为采集，形成闭环

同时 @Scheduled(cron = "0 0 2 * * ?") 每天凌晨全量离线重建，确保数据一致性

@Async 异步刷新 @Scheduled 离线重建 Redis 缓存 手动触发重算
